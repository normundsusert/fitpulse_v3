FITPULSE WEB — COMPACT DASHBOARD v7

ГЛАВНОЕ
- Главный экран: рекомендация на сегодня, план недели, Workout Score, динамика объёма, вес и питание под цель.
- Тренировка: подходы, ощущения, корректировка следующего подхода, рекомендованный отдых без таймера.
- Замеры: вес и окружности.
- Прогресс: нажми на любое упражнение, чтобы открыть всю историю его выполнения по датам и подходам.
- AI-тренер открывается с главного экрана и не занимает отдельную постоянную вкладку.

ДАННЫЕ
- Пароль при запуске не используется.
- Данные сохраняются локально в браузере/PWA.
- Старое парольное хранилище при необходимости можно один раз перенести через старый пароль.

ОБНОВЛЕНИЕ GITHUB PAGES
Заменить index.html, manifest.webmanifest, sw.js, README_RU.txt и папку icons. После обновления полностью закрой FitPulse и открой заново.
