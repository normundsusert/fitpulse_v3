FITPULSE v9 — GPT + ПАМЯТЬ

Что изменилось:
- Gemini полностью удалён.
- GPT работает через защищённый backend: API-ключ OpenAI не хранится в браузере и не публикуется в GitHub.
- Каждый профиль FitPulse хранит свой OpenAI Conversation ID, поэтому GPT продолжает диалог и анализ прогресса между тренировками на этом устройстве.
- FitPulse также хранит локальную краткую память тренера (цель, тренды и важные договорённости), которую GPT обновляет после ответов.
- Можно вставить старую сводку/прогресс из обычного ChatGPT. Она будет использоваться как исходный контекст.
- Обычная память ChatGPT аккаунта НЕ доступна FitPulse автоматически; ChatGPT и OpenAI API — отдельные системы.

Чтобы включить GPT:
1. Разверни backend из папки backend/ (инструкция backend/README.md).
2. В FitPulse открой GPT-тренера → GPT · подключение и память.
3. Вставь URL вида https://....workers.dev/api/chat.
4. Нажми «Проверить GPT».
5. При желании включи автоматический GPT-разбор после тренировок.

Без backend все локальные функции FitPulse (тренировки, прогрессия, история, замеры и локальная сводка) продолжают работать.
