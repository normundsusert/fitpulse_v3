FITPULSE WEB — WORKOUT ASSISTANT v5

Главный фокус этой версии — помощь прямо во время тренировки.

Что нового:
- отдельный раздел питания удалён;
- в профиле/сводке остаются простые ориентиры по белку и углеводам для выбранной цели;
- после каждого подхода нажми ✓ и отметь ощущение: Легко / Нормально / Тяжело / Предел / Боль или дискомфорт;
- FitPulse автоматически предлагает вес и повторы следующего подхода;
- после завершения подхода автоматически запускается рекомендуемый отдых;
- базовые упражнения получают более длинный отдых, изолирующие — более короткий;
- при отметке боли/дискомфорта приложение не советует продолжать упражнение через боль;
- во время тренировки показывается прогресс выполненных подходов;
- история сохраняет ощущения и рекомендации после подходов;
- расширена библиотека упражнений и сохранены подсказки по технике;
- пароль при обычном запуске не используется. Старое зашифрованное хранилище можно разово перенести старым паролем.

Данные хранятся локально на устройстве. Gemini используется только при явном запросе пользователя и требует личный API-ключ.

Публикация: загрузить index.html, manifest.webmanifest, sw.js и папку icons в корень GitHub Pages репозитория.
