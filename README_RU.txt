FITPULSE PWA — ЗАЩИЩЁННАЯ ВЕРСИЯ

ЧТО ВНУТРИ
- index.html — приложение с парольной блокировкой и локальным шифрованием
- manifest.webmanifest — параметры установки PWA
- sw.js — кэш оболочки для офлайн-запуска
- icons/ — иконки

ЗАЩИТА ДАННЫХ
- При первом запуске создай пароль (минимум 8 символов). При каждом новом открытии потребуется пароль. Есть кнопка «Заблокировать»; приложение также блокируется при переходе в фон.
- История, замеры, текущая тренировка, настройки и Gemini API-ключ шифруются в браузере с помощью AES-256-GCM. Ключ шифрования выводится из пароля через PBKDF2-SHA-256 (310 000 итераций).
- Пароль не сохраняется и не отправляется в сеть. Соль и зашифрованный контейнер хранятся в localStorage; открытые данные существуют в памяти приложения только пока оно разблокировано.
- Сервер получает только статические файлы приложения. Нет аккаунтов, общей базы данных, аналитики или облачной синхронизации.
- Если включить Gemini, после отдельного подтверждения в Google отправляются текст тренировки и самочувствие для анализа. API-ключ также хранится в зашифрованном контейнере.
- Экспорт создаёт зашифрованный файл резервной копии. Для импорта нужен пароль, которым была создана эта копия.
- Если пароль потерян, восстановить данные без правильного пароля или доступной резервной копии нельзя. Храни резервную копию отдельно.
- Шифрование защищает данные в хранилище, но не от вредоносного ПО, взломанного устройства или человека, который получил доступ к приложению в уже разблокированном состоянии.
- На одном устройстве данные хранятся в профиле конкретного браузера/PWA. Safari и установленная на экран «Домой» версия могут иметь раздельные хранилища.

ПУБЛИКАЦИЯ (GITHUB PAGES)
1. Создай публичный репозиторий GitHub, например fitpulse.
2. Загрузи ВСЕ файлы и папку icons в корень репозитория.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. После публикации открой HTTPS-ссылку.
5. iPhone: Safari → Поделиться → На экран «Домой» → Добавить. Запускай затем с иконки.
6. Android: Chrome → меню → Установить приложение / Добавить на главный экран.

GEMINI
1. Получи личный API-ключ на https://aistudio.google.com/apikey
2. В приложении открой История → Gemini AI, введи ключ и проверь подключение.
3. Каждый пользователь использует собственный ключ. Не публикуй его в репозитории.
4. Gemini требует интернет. Без запроса к Gemini тренировочные данные остаются на устройстве.

ВАЖНО
Это устанавливаемое веб-приложение (PWA), а не приложение из App Store / Google Play. Для Web Crypto и установки требуется HTTPS. Архив сам по себе не является приложением, его сначала нужно разместить на HTTPS-хостинге.
